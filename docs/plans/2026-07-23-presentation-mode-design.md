# 演示模式设计

## 目标

在当前文档中点击 `Present` 后进入 macOS 全屏展示，隐藏文件夹侧栏和普通 Reader 工具栏，保留正文、演示工具栏与现有大纲。演示过程中可以调整正文字号，大纲仍支持章节跳转、收起和展开。

## 设计结论

- 复用当前 `BrowserWindow`，由主进程调用 Electron 全屏能力，不创建额外窗口。
- 每个窗口单独保存演示状态，多个文件夹窗口之间互不影响。
- 复用现有 Reader 和大纲组件，进入演示时不卸载 Reader，避免丢失大纲收起状态和当前章节状态。
- 演示字号默认 `22px`，每次调整 `2px`，范围为 `18px` 到 `34px`。
- 支持工具栏按钮以及 `Command/Ctrl +`、`Command/Ctrl -`、`Command/Ctrl 0` 调整或重置字号。
- 演示工具条展开后连续 3 秒没有工具条操作会自动收起为顶部 `Aa` 小按钮；点击小按钮重新展开，工具条内的操作会重新计时。
- 收起和展开使用固定高度的顶部区域，避免正文滚动位置因工具条尺寸变化而跳动。
- 点击 `Exit`、按 `Esc` 或通过 macOS 系统控件退出全屏，都会恢复普通 Reader 布局。

## 状态流转

1. 渲染进程点击 `Present`，切换到预览并请求主进程开启演示模式。
2. 主进程记录发起请求的窗口并调用 `setFullScreen(true)`。
3. 渲染进程隐藏普通工具栏和文件夹侧栏，显示演示工具栏。
4. 退出时主进程清理该窗口状态，并通知渲染进程恢复普通布局。
5. 如果用户从 macOS 系统层退出全屏，`leave-full-screen` 事件负责同步状态。

## 边界处理

- Markdown 存在未保存内容、正在保存或发生外部修改冲突时，暂不允许进入演示，避免展示旧内容。
- HTML 为只读文档，可以直接进入演示。
- 演示模式中打开 Mermaid 图表后，图表查看器继续使用自己的缩放、拖动和关闭操作。
- 演示模式中通过其他入口打开文件夹时，先退出演示，避免出现没有当前文档的全屏空页。

## 验证范围

- 字号步长、默认值、上下限和工具条自动收起规则使用自动化测试覆盖。
- 执行 TypeScript 类型检查、全部测试和生产构建。
- macOS 全屏切换、工具栏、大纲跳转、收起展开及系统 `Esc` 退出需要在可运行应用中手动验证；如果 IOA 阻止未备案应用启动，由用户手动完成。
