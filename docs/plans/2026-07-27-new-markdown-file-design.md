# 新建 Markdown 文件设计

## 目标

支持从首页、Reader 顶部工具栏和 macOS File 菜单新建空白 Markdown 文档。新文档立即进入 Edit 模式；首次点击 Save 时使用系统保存窗口填写文件名并选择目录，保存成功后转为普通 Markdown 文件并继续使用现有自动保存、文件监听、最近文件和文件夹刷新能力。

## 方案比较

1. 点击 New 时立即弹出保存窗口：实现简单，但不符合“保存时命名和选择位置”，用户还没开始编辑就必须决定路径。
2. 使用空路径模拟普通文件：改动较小，但空字符串的语义不清晰，容易误触发自动保存和文件监听。
3. 为渲染进程中的文档增加明确的 `isNew` 状态：首次保存走独立 IPC，成功后返回普通文件。状态清晰，现有保存逻辑只需增加一个分支。

采用方案 3。

## 状态与数据流

- New 入口调用主进程，主进程通知当前窗口创建未命名文档，并停止旧文档监听；已打开的文件夹及其监听保持不变。
- 渲染进程创建 `Untitled.md` 空白文档，设置 `isNew: true`、切换到 Edit 模式，并保留当前文件夹作为首次保存的默认目录。
- 新文档未落盘前不参与 1 秒自动保存，也不进入最近文件列表。
- 新文档在首次保存前仍可在 Edit 与 Preview 之间切换；Markdown 预览直接渲染当前草稿，不依赖磁盘内容。
- 首次 Save 调用 `save-new-markdown-file`。主进程打开系统保存窗口，默认文件名为 `Untitled.md`；无扩展名时补充 `.md`，非 Markdown 扩展名则拒绝保存。
- 用户取消保存时保留草稿和 Edit 模式，不显示错误。
- 保存成功后启动文档监听、更新窗口标题、加入最近文件，并将渲染进程状态替换为普通 Markdown 文件。若目标位于当前打开的文件夹，现有文件夹监听会自动刷新侧边栏。

## 界面

- 首页增加 `New File`。
- Reader 顶部工具栏增加 `New`。
- macOS File 菜单增加 `New Markdown File`，快捷键为 `Command+N`；原 `Open Folder in New Window` 保留 `Shift+Command+N`。
- 未命名文档路径位置显示 `Not saved yet`，保存状态显示 `Unsaved`。

## 异常与边界

- 保存窗口取消不视为失败。
- 保存失败时保留全部草稿，并在 Reader 中显示错误。
- 新文档不能进入演示模式，直到首次保存成功。
- HTML 仍保持只读，不改变现有行为。

## 验证

- 单元测试覆盖默认文件名、自动补充 `.md`、保留 `.markdown`、拒绝其他扩展名，以及未保存 Markdown 草稿预览。
- 执行 TypeScript 类型检查、全部测试和生产构建。
- 生成 arm64 DMG，并验证应用签名和 DMG 校验和。
- 界面流程由用户手动验证，避免 IOA 对未备案应用启动的干扰。
